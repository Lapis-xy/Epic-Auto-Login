# Epic Auto-Login (Password Manager)

Uno strumento sviluppato per automatizzare la procedura di accesso agli account **Epic Games**, compilando in automatico i campi di **email** e **password** in modo rapido e senza doverli digitare manualmente ogni volta.

---

## Caratteristiche principali

- **Compilazione automatica:** Inserisce automaticamente email e password nella schermata di login di Epic Games.
- **Risparmio di tempo:** Elimina la necessità di copiare e incollare le credenziali ad ogni avvio o cambio account.
- **Gestione semplificata:** Pensato per velocizzare l'accesso al launcher o al portale web di Epic Games.

---

## Come funziona

1. Il programma avvia o individua la finestra/pagina di accesso di Epic Games.
2. Recupera le credenziali configurate dall'utente (email e password).
3. Compila automaticamente i rispettivi campi e avvia la procedura di login.

---

## Requisiti e Installazione

1. Clona la repository:
   ```bash
   git clone https://github.com/Lapis-xy/passwordManager.git
   cd EpicPasswordManager
   ```
2. Installa le eventuali dipendenze richieste dal progetto.
3. Configura le tue credenziali nel file di configurazione o nelle variabili d'ambiente previste.
